vSmith / Software

Missing Software

If you are unable to locate a required software application inside vSmith, follow these steps to verify your access, check desktop pools, or submit an IT entitlement request.

🔍︎ Step 1: Confirm Your Application Access

Before requesting access, ensure you are logging in with the correct credentials and checking all published desktop environments.

1. Verify Credentials

Install and open the Omnissa Horizon Client. Log in using your UMD Directory ID.

Username Format: First half of your @umd.edu or @terpmail.umd.edu address (Do NOT use your 9-digit UID number).

2. Check the "Student Desktop"

Certain software titles (such as Palisades, IDEA, or Tableau) are not published as standalone icons and are accessible only inside the full Student Desktop session.

Browse Full Software List ↗

📩︎ Step 2: Faculty Verification & Support Request

Faculty Request Requirement

Smith IT contacts faculty members prior to each semester to collect software requirements. If an application is missing for your entire class, your instructor may need to submit a formal software request for the current term.

Submit a Missing Software Ticket

If your classmates have access to required course software in the Workspace Portal but you do not, please email the Office of Smith IT Service Desk at helpme@rhsmith.umd.edu with the following details:

  • Full Name
  • Official Email Address: Your @umd.edu address
  • Course Number: The course requiring vSmith software access
  • Professor's Name: Your course instructor
  • Software Title: The exact application name you need to access
