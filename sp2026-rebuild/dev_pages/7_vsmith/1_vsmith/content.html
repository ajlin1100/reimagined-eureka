vSmith Virtual Desktop Environment

vSmith is a cloud-based virtual computer lab providing essential academic and analytical software to students, faculty, and staff. Hosted securely in the Smith IT data center, high-performance virtual desktops and standalone applications are accessible 24/7/365 from any device, anywhere in the world.

💡︎ Key Advantages for Students & Faculty

vSmith eliminates physical hardware constraints by streaming enterprise business software straight to your laptop, tablet, or home desktop environment.

💰︎

Zero Additional Cost

Access high-tier commercial software tools required for course work without purchasing individual software licenses.

🕒︎

24/7 Remote Flexibility

Complete assignments and conduct complex computations on your own schedule without visiting on-campus computer labs.

💻︎

Cross-Platform Support

Run Windows-exclusive course software seamlessly on macOS, Linux, ChromeOS, and mobile hardware setups.

⚡︎ Getting Started: Client Installation & Login

Follow these quick setup instructions to configure the native Horizon connection client on your personal computer:

1

Download & Install Omnissa Horizon Client

Visit the official download repository to get the native client installer for your operating system (Windows, macOS, or mobile). Complete the installer using all default configuration options.

📥︎ Download Omnissa Horizon Client
2

Add the Smith Server Address

Launch the Omnissa Horizon Client application from your Start Menu (Windows) or Finder (macOS). Click to add a new server, and enter the following connection address:

desktop.rhsmith.umd.edu

Once saved, double-click the server connection icon to initiate authentication.

3

Authenticate with Directory ID & Duo Multi-Factor

At the login prompt, enter your University Directory ID (the prefix of your campus email address prior to @umd.edu) and your password.

Select the Student Desktop pool. Upon hitting the Windows login prompt within the virtual desktop, re-enter your Directory ID credentials and approve the push notification via Duo Multi-Factor Authentication.

☁︎ Saving Your Work: Kumo & Terpdrive Integration

Because vSmith operates on non-persistent virtual machines, virtual desktop sessions are reset automatically when you log off. Any files saved locally to the temporary virtual machine desktop will be permanently deleted upon session termination.

⚠︎ Critical Data Preservation Requirement

vSmith integrates with Kumo to mount your preferred cloud storage provider directly into your virtual desktop file explorer. Before closing your session, always save your documents, datasets, and project files directly to your connected cloud drive:
