Installing New Software for Classes

Only faculty and staff can request software additions for classroom and lab computers. Software requests must be submitted using the official request form for all Business School course delivery locations, including remote sites.

Semi-Annual Deployment Deadlines

Classroom software images are highly complex, undergo rigorous stability testing, and are locked down to prevent unauthorized changes during the academic term. Updates are executed twice a year ahead of each major semester:
