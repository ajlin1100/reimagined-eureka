Shell Shop Order in Workday

 

The following are step-by-step instructions for completing a “Shell Shop Order” in Workday. Use Shell Shop orders for any company listed as a Storefront supplier in Shell Shop. If the supplier is not a Shell Shop supplier, use Non-Catalog Orders in Workday instructions.

 

Note: Labor Cost Configuration for Capital Assets

When a Capital Asset and Labor/Installation is included on the requisition, calculate the specific labor cost allocation using the following formula sequence:

1. [Capital Asset Amount] x 100 = [Base Multiplier]
2. [Base Multiplier] ÷ [Total Labor/Installation Amount] = [Factor]
3. [Factor] x 100 = Labor Cost Allocation

Example:

$5,200 (CA) x 100 = 520,000 ÷ $33,000 (L) = 15.7575 x 100 = $1,575.00

*This calculated amount represents the labor cost for the individual Capital Asset. It must be entered as a distinct line item on the REQ and subsequently subtracted from the gross total of the primary Installation/Labor line item. Under "Review Required" use "Modify System or Asset", and in the memo of this line item, note the description of the Capital Asset for labor cost.

 ** Subtract all individual labor cost entries from the total cost of the Installation/Labor line item.

Critical Accounting & Logistics Attributes Required:


  • Requisition Type: Determines operational routing paths (refer to the classification map below).

  • USource Number: Identifies the specific department accounts covering the acquisition. Cross-reference these indices on the Procurement Codes Sheet.

  • Location Asset ID: Destination where the items will be placed. Enter the room designation (e.g., 3520J) and select the corresponding facility mapping from the auto-complete array list.

Completion of the REQUEST (REQ)

The comprehensive breakdown below details the remaining administrative information inputs required during order checkout phases to ensure successful routing logs.

  • Memo to Suppliers Block: Input your reference quote identifiers along with target end-user / structural destination profiles.
    Format Example: Quote #987654 - Attn: Jane Doe / Room 3520

  • Internal Memo Field: Re-apply the strict string index layout applied at row levels:
    Project Code / FY / Vendor Name / Item Details

  • Audit Checks: Scroll through the system autofill text fields to confirm the accuracy of institutional profile information.

  • Requested Delivery Date Field: Open the system calendar dialog and specify the exact date the baseline document packet is being submitted to workflows.

Line Item Financial Audit Guardrails (>$5K Rules)

  • Review Required Flag: This dropdown choice is absolutely mandatory for each singular line element containing an individual Unit Cost of $5,000 or greater.

  • Select the option attribute value marked "New" in most instances. Alternate values are reserved for formal Change Orders processed by designated Cost Center managers.

  • Additional Worktags Warning: Do NOT delete, overwrite, or mutate any automatically mapped strings or values populated inside this column field.

*Note on Services: Service lines require no secondary data entries during checkout stages, as full lifecycle dates remain captured during initial line creation.

Document Attachments Module

To finalize compliance metrics, drag and drop target file sheets directly into the active UI Drop Zone, or select files manually via system explorers.

Once files populate the upload queue, you must apply explicit indexing metrics to each item:

  • Assign a matching Attachment Category from the default profile dictionary catalog.

  • Add a concise document summary within the Comments block or paste the standardized Internal Memo string.

  • Ensure the checkbox option labeled "External" remains unchecked.

Attachment Category Selection Matrix

  • Delegated Agreement Requiring Signature: Maps to any contract, software licensing agreement, or legal text sheet requiring formal UMD administrative signature clearance.

  • Quote: Standard vendor itemization invoice/cost breakdown files.

  • Scope of Work: Detailed technical sheets mapping exact operational tasks to be completed by the contract vendor.

  • Supporting Documentation: General supplemental logs covering validation proofs, single-source justifications, or general corporate Terms & Conditions documents.

 

Submitting the REQ

Once all entries are fully balanced and attachments properly labeled, click the green "Submit" action button to trigger the institutional procurement lifecycle.

  • Approval Route 1: Form review transitions to the localized Cost Center designees and Business Managers mapped to the specific department USource string.

  • Approval Route 2: Following local clearance, files transfer to the Campus Procurement Level for final Purchase Order (PUR) generation.

Post-Submission Logging Steps

The instance processing screen displays your official 10-digit Requisition identity handle (e.g., REQ-XXXXXXXXXX).
